## Getting Started

1. **Install Fluent UI v9**:
   To begin migration, install the latest Fluent UI React v9 package.

   ```bash
   npm install @fluentui/react-components
   ```

2. **Update Imports**:
   Update your component imports to use the v9 components. Use the component mapping table below to assist.

3. **Refactor Code**:
   Refactor your code to accommodate changes in API, props, and new functionalities provided by v9 components.

## New Components in v9

React v9 introduces several new components that were not present in v8:

- [**Accordion**](/react/components/accordion): Allowing to toggle the display of content by expanding or collapsing sections.
- [**Avatar**](/react/components/avatar): Replaces `Persona` for rendering user images.
- [**AvatarGroup**](/react/components/avatar-group): Replaces `Facepile`.
- [**Badge**](/react/components/badge/badge): Displays text and/or an icon.
- [**CounterBadge**](/react/components/badge/counter-badge): Displays Badge numerical values.
- [**PresenceBadge**](/react/components/badge/presence-badge): Displays Badge status.
- [**Carousel**](/react/components/carousel/carousel): Sliding window of elements controlled by previous, next, and direct pagination buttons.
- [**Drawer**](/react/components/drawer): Replaces `Panel` for side-drawer navigation.
- [**InfoLabel**](/react/components/badge/presence-badge):An InfoLabel is a Label with an InfoButton at the end.
- [**Popover**](/react/components/popover): Enhanced version of `Callout` with improved accessibility.
- [**TabList**](/react/components/tab-list): Replaces `Pivot` for tabbed navigation.
- [**ProgressBar**](/react/components/progress-bar): Renamed from `ProgressIndicator`, with similar functionality but refined API.
- [**Input**](/react/components/input): A new input component replacing `TextField` for simpler text input handling.
- [**Skeleton**](/react/components/skeleton): A new input component replacing `Shimmer`.
- [**Switch**](/react/components/switch): A new component replacing `Toggle` for binary options.
- [**SwatchPicker**](/react/components/swatch-picker): A new component replacing `SwatchColorPicker` with added functionality.
- [**Toast**](/react/components/badge/presence-badge):A Toasts displays temporary content to the user.
- [**TeachingPopover**](/react/components/teaching-popover): A new component in v9 that replaces `TeachingBubble` and `Coachmark` in v8.
