# Component Migration

This page is the canonical v8-to-v9 migration inventory for the public React v8 example keys registered in `apps/public-docsite-resources/src/AppDefinition.tsx`. Every backticked `v8 key` below appears exactly once and keeps the exact `AppDefinition.examplePages[*].links[*].key` spelling for direct child example links whose `url` matches `#/examples/<page>`.

Published handbook pages are linked only from the **Guide pages** column. Planned P0 pages stay plain text until the central MDX guide exists and is ready to publish.

## Getting Started

1. Install Fluent UI v9:

   ```bash
   npm install @fluentui/react-components
   ```

2. Update imports from `@fluentui/react` to `@fluentui/react-components` as you migrate each scenario.
3. Refactor APIs with the inventory and linked guides: many v9 destinations use renamed props, compound components, slots, and child composition instead of v8 render callbacks.

## Inventory legend

- **Status**
  - `missing`: at least one required central guide page does not exist yet.
  - `in progress`: every required guide page exists, but at least one page still fails the handbook completion checks.
  - `complete`: every required guide page passes every handbook completion check.
  - `no direct counterpart`: no stable v9 component serves the same primary task.
  - `out of scope`: the only destination is preview, compat, utility, deprecated, or third-party functionality.
- **Complexity**
  - `high`: a migration needs a scenario decision across multiple stable destinations, three or more required compound components, or custom implementation for a core v8 scenario.
  - `medium`: no `high` rule applies, but migration changes controlled state, event data shape, accessible labeling, focus or keyboard behavior, or replaces render callbacks with child composition.
  - `low`: migration is limited to renames, enum changes, or native HTML and ARIA replacements.
  - `N/A`: used only for temporary placeholders or rows that do not currently publish a guide.
- **Priority**
  - `P0`: the ten guide families approved for the first handbook batch.
  - `P1`: a missing guide with `high` or `medium` complexity.
  - `P2`: a missing guide with `low` complexity.
  - `N/A`: complete, out-of-scope, no-direct-counterpart, or temporary placeholder rows.
- **Guide-family status**
  - Rows with multiple guide pages aggregate across every listed page. A family stays `missing` until all required pages exist, stays `in progress` until all existing pages pass completion checks, and becomes `complete` only when every listed page is complete.
- **v9-only coverage**
  - Stable v9 components with no canonical v8 source stay in the **New Components in v9** section instead of receiving migration rows.

## Out-of-scope categories

Canonical rows stay in this inventory even when the current destination is preview, compat, utility, deprecated, or third-party functionality. Those rows are recorded as `out of scope` until a stable `@fluentui/react-components` destination can be audited and documented.

## New Components in v9

Stable v9-only components stay here instead of receiving migration rows:

- [**Accordion**](/docs/components-accordion--docs): Allows users to expand and collapse related content.
- [**Avatar**](/docs/components-avatar--docs): Replaces `Persona` for rendering user images.
- [**AvatarGroup**](/docs/components-avatargroup--docs): Replaces `Facepile`.
- [**Badge**](/docs/components-badge-badge--docs): Displays text and/or an icon.
