# Dropdown / Combobox Migration

## Overview

In v8, both components are **data-driven**: pass an `options` array of `IDropdownOption` / `IComboBoxOption` objects.

In v9, both are **declarative**: compose `<Option>` (and `<OptionGroup>`) as JSX children. This is the same pattern shift as `ContextualMenu` → `Menu`.

The `onChange` callback is also renamed to `onOptionSelect` with a different signature.

`VirtualizedComboBox` has no one-prop replacement. Migrate selection and input
behavior to `Combobox`, then preserve virtualization as a separate rendering
concern and validate active-option announcements, scrolling, and keyboard
navigation with the full data set.

## Examples

### Basic Migration

Basic v8 usage:

```tsx
// v8
import { Dropdown, IDropdownOption } from '@fluentui/react';

const options: IDropdownOption[] = [
  { key: 1, text: 'Apple' },
  { key: 'banana', text: 'Apple' },
  { key: 'cherry', text: 'Cherry', disabled: true },
];

<Dropdown
  label="Fruit"
  placeholder="Select an option"
  options={options}
  selectedKey={selectedKey}
  onChange={(_, option) => option && selectFruit(option)}
/>;
```

```tsx
// v9
import * as React from 'react';
import { Dropdown, Option, Field } from '@fluentui/react-components';

type FruitOption = { key: string | number; text: string; disabled?: boolean };
const options: FruitOption[] = [
  { key: 1, text: 'Apple' },
  { key: 'banana', text: 'Apple' },
  { key: 'cherry', text: 'Cherry', disabled: true },
];
const toOptionId = (key: string | number) => `${typeof key}:${String(key)}`;
const optionsById = new Map(options.map(option => [toOptionId(option.key), option]));

function FruitDropdown() {
  const [selectedId, setSelectedId] = React.useState('');
  const [displayValue, setDisplayValue] = React.useState('');

  return (
    <Field label="Fruit">
      <Dropdown
        placeholder="Select an option"
        value={displayValue}
        selectedOptions={selectedId ? [selectedId] : []}
        onOptionSelect={(_, data) => {
          const nextId = data.optionValue ?? '';
          const option = optionsById.get(nextId);
          setSelectedId(option ? nextId : '');
          setDisplayValue(option?.text ?? '');
          if (option) {
            selectFruit(option);
          }
        }}
      >
        {options.map(option => (
          <Option
            key={toOptionId(option.key)}
            value={toOptionId(option.key)}
            text={option.text}
            disabled={option.disabled}
          >
            {option.text}
          </Option>
        ))}
      </Dropdown>
    </Field>
  );
}
```

v8 option keys can be strings or numbers and the callback returns the original
`IDropdownOption` (including its key and application data). v9 option values
and `selectedOptions` are strings. Canonicalize every key to a stable string ID
and keep an ID-to-model lookup as above. Include the original key type in the
encoding so numeric `1` cannot collide with string `"1"`.

`onOptionSelect` returns `optionValue`, `optionText`, and the complete
`selectedOptions` string array; it does not return the original option object
or its array index. Resolve the model from `optionValue`/`selectedOptions`.
Never use display text as identity because duplicate labels are valid. When
controlling selection, control the displayed `value` from the same resolved
model so the button text and `selectedOptions` cannot drift apart.

**Multi-select:** Replace `multiSelect` with `multiselect`. Store the selected keys in
`selectedOptions`; `onOptionSelect` returns the complete next selection.

**Grouped options:** Replace v8 header and divider options with `OptionGroup`.
Render each selectable item as an `Option`; v9 has no `OptionDivider`.

### Combobox

A v8 `ComboBox` with `allowFreeform` maps to a v9 `Combobox` with `freeform`:

```tsx
import * as React from 'react';
import { Combobox, Field, Option } from '@fluentui/react-components';

function FreeformFruitPicker({ preserveV8InlineAutocomplete }: Props) {
  const options = [
    { key: 'apple', text: 'Apple' },
    { key: 'banana', text: 'Banana' },
  ];
  const optionsByKey = new Map(options.map(option => [option.key, option]));
  const [inputValue, setInputValue] = React.useState('');
  const [selectedKey, setSelectedKey] = React.useState('');
  const [open, setOpen] = React.useState(false);
  const committed = React.useRef({ inputValue: '', selectedKey: '' });
  const dirty = React.useRef(false);
  const keyboardNavigated = React.useRef(false);
  const activeOptionText = React.useRef<string | undefined>(undefined);
  const inputRef = React.useRef<HTMLInputElement>(null);
  const comboboxRootRef = React.useRef<HTMLDivElement>(null);

  const activeOptionMatchesInput = (inputValue: string) => {
    const normalizedActiveText = activeOptionText.current?.toLocaleLowerCase();
    const normalizedInput = inputValue.toLocaleLowerCase();
    return normalizedActiveText === normalizedInput;
  };

  const findExactOption = (text: string) =>
    options.find(option => option.text.toLocaleLowerCase() === text.toLocaleLowerCase());

  const findPrefixOption = (text: string) =>
    text ? options.find(option => option.text.toLocaleLowerCase().startsWith(text.toLocaleLowerCase())) : undefined;

  const selectOption = (option: (typeof options)[number]) => {
    setSelectedKey(option.key);
    setInputValue(option.text);
    committed.current = { inputValue: option.text, selectedKey: option.key };
    onOptionCommit(option);
  };

  const restoreCommitted = () => {
    dirty.current = false;
    keyboardNavigated.current = false;
    setInputValue(committed.current.inputValue);
    setSelectedKey(committed.current.selectedKey);
  };

  const commitFreeform = (text: string) => {
    if (!dirty.current) {
      return;
    }
    dirty.current = false;
    keyboardNavigated.current = false;
    setOpen(false);

    const matchingOption = findExactOption(text);
    if (matchingOption) {
      selectOption(matchingOption);
      return;
    }

    const validationValue = text.trim();
    if (!validationValue || !isValidFreeformValue(validationValue)) {
      setInputValue(committed.current.inputValue);
      setSelectedKey(committed.current.selectedKey);
      return;
    }

    setSelectedKey('');
    setInputValue(text);
    committed.current = { inputValue: text, selectedKey: '' };
    onFreeformCommit(text);
  };

  return (
    <Field label="Fruit">
      <Combobox
        ref={inputRef}
        root={{ ref: comboboxRootRef }}
        inlinePopup
        open={open}
        value={inputValue}
        selectedOptions={selectedKey ? [selectedKey] : []}
        onOpenChange={(_, data) => setOpen(data.open)}
        onActiveOptionChange={(_, data) => {
          activeOptionText.current = data.nextOption?.text;
        }}
        onChange={event => {
          const typedValue = event.target.value;
          const inputEvent = event.nativeEvent as InputEvent;
          const isDeletion = inputEvent.inputType?.startsWith('delete');
          const caretAtEnd = event.target.selectionStart === typedValue.length;
          const prefixOption = findPrefixOption(typedValue);
          dirty.current = true;
          keyboardNavigated.current = false;
          activeOptionText.current = prefixOption?.text;
          setSelectedKey('');
          const completion = preserveV8InlineAutocomplete && !isDeletion && caretAtEnd ? prefixOption : undefined;
          setInputValue(completion?.text ?? typedValue);
          if (completion && completion.text.length > typedValue.length) {
            requestAnimationFrame(() => inputRef.current?.setSelectionRange(typedValue.length, completion.text.length));
          }
        }}
        onOptionSelect={(_, data) => {
          const option = data.optionValue ? optionsByKey.get(data.optionValue) : undefined;
          if (!option) {
            return;
          }

          dirty.current = false;
          selectOption(option);
        }}
        onKeyDownCapture={event => {
          if (event.key === 'Escape' && dirty.current) {
            restoreCommitted();
            return;
          }
          if (['ArrowDown', 'ArrowUp', 'Home', 'End', 'PageUp', 'PageDown'].includes(event.key)) {
            keyboardNavigated.current = true;
            return;
          }
          if (
            (event.key === 'Enter' || event.key === 'Tab') &&
            dirty.current &&
            !keyboardNavigated.current &&
            !activeOptionMatchesInput(event.currentTarget.value)
          ) {
            if (event.key === 'Enter') {
              event.preventDefault();
            }
            event.stopPropagation();
            commitFreeform(event.currentTarget.value);
          }
        }}
        onBlur={event => {
          const nextTarget = event.relatedTarget as Node | null;
          if (!nextTarget || !comboboxRootRef.current?.contains(nextTarget)) {
            commitFreeform(inputValue);
          }
        }}
        freeform
      >
        {options.map(option => (
          <Option key={option.key} value={option.key} text={option.text}>
            {option.text}
          </Option>
        ))}
      </Combobox>
    </Field>
  );
}
```

`freeform` permits unmatched text, but it does not turn that text into an
option selection. `onOptionSelect` runs only when a concrete active `Option` is
selected. It also runs with `optionValue: undefined` and an empty
`selectedOptions` array when a single selection is cleared, including when
typing away from a selected option or using the clear button, so guard that
case. If v8 `allowFreeform` committed unmatched text, add explicit Enter, Tab,
and blur handling as above: parse and validate the input, update the domain
value, and either normalize the display string or restore the last committed
value and selected key. Track whether input is dirty so keyboard commit followed
by blur, selection followed by blur, and an untouched blur do not fire the
domain callback twice. On blur, resolve an untrimmed, case-normalized exact
option match before committing unmatched text. A v8 autocomplete prefix counts
as a match only while its completed suffix remains in the input; after deletion
or a mid-string edit, the remaining prefix follows the freeform path. Use
capture-phase handling for unmatched Enter and Tab input; the base Combobox may
keep an unrelated option active and handles its own bubble-phase key event
before a normal `onKeyDown` callback. Prevent the default action for Enter, but
not Tab, so focus can still move. Let unedited Enter/Tab, keyboard navigation,
and an exact active option reach the base handler. Restore the last committed
input and selection on Escape, then let the base handler close the popup. The
example uses `inlinePopup` and a root ref so moving focus into the listbox is
not mistaken for leaving the complete control. A captured freeform Enter
bypasses the base close behavior, so control `open` and close it explicitly
after committing.

v8 `autoComplete="on"` performs inline option completion. The same-named v9
prop is the native HTML autocomplete attribute and does not reproduce that
behavior. The example preserves it by replacing a typed prefix with the first
matching option and selecting only the completed suffix through the forwarded
input ref. Skip completion for deletions and edits made away from the end of the
input so users can erase or edit the completed value. Omit that branch for v8
`autoComplete="off"`; otherwise treat removal of inline completion as an
intentional UX change.

`allowFreeInput` has a different v8 contract from `allowFreeform`: it permits
temporary unmatched typing while focused, but on blur it selects a matching
option or restores the previous selection. For that prop, keep the typed value
as pending UI state and do not call the unmatched-value commit callback.

Filter the rendered `Option` children for autocomplete. `VirtualizedComboBox`
has no direct replacement; preserve virtualization separately and verify
keyboard navigation and active-option announcements.

## Prop Mapping

### IDropdownOption → Option

| v8 `IDropdownOption` | v9 `Option`              | Notes                                                           |
| -------------------- | ------------------------ | --------------------------------------------------------------- |
| `key`                | canonical string `value` | Encode string/number keys and retain an ID-to-model lookup      |
| `text`               | `children`               | `<Option>Apple</Option>`                                        |
| `disabled`           | `disabled`               |                                                                 |
| `hidden`             | —                        | Remove from the list instead                                    |
| `title`              | `title`                  |                                                                 |
| `itemType: Header`   | `OptionGroup` label      | See grouped options example above                               |
| `itemType: Divider`  | `OptionGroup` boundary   | No `OptionDivider` in v9; use separate `<OptionGroup>` elements |

### IDropdownProps → DropdownProps

| v8                   | v9                               | Notes                                                                 |
| -------------------- | -------------------------------- | --------------------------------------------------------------------- |
| `options`            | `<Option>` children              | Each `IDropdownOption` → `<Option>`                                   |
| `selectedKey`        | `selectedOptions={[id]}`         | Convert the v8 key to its canonical string ID                         |
| `selectedKeys`       | `selectedOptions={ids}`          | Convert every v8 key; multi-select returns the complete ID array      |
| `defaultSelectedKey` | `defaultSelectedOptions={[id]}`  | Convert the v8 key to its canonical string ID                         |
| `onChange`           | `onOptionSelect`                 | Resolve original models from string `optionValue` / `selectedOptions` |
| `placeholder`        | `placeholder`                    |                                                                       |
| `label`              | `<Field label="...">` wrapper    | Same as other form controls                                           |
| `disabled`           | `disabled`                       |                                                                       |
| `required`           | `required` on `<Field>`          |                                                                       |
| `errorMessage`       | `validationMessage` on `<Field>` |                                                                       |
| `multiSelect`        | `multiselect`                    | Casing change                                                         |
| `calloutProps`       | `Listbox` props / `positioning`  |                                                                       |
| `styles`             | `className` + `makeStyles`       |                                                                       |
| `theme`              | `FluentProvider`                 |                                                                       |
| `componentRef`       | `ref`                            |                                                                       |

### IComboBoxProps → ComboboxProps

| v8                   | v9                                    | Notes                                                                                   |
| -------------------- | ------------------------------------- | --------------------------------------------------------------------------------------- |
| `options`            | `<Option>` children                   |                                                                                         |
| `selectedKey`        | `selectedOptions={[key]}`             |                                                                                         |
| `onChange`           | `onOptionSelect` + input handlers     | List picks select options; unmatched text needs explicit Enter/blur commit              |
| `allowFreeform`      | `freeform`                            |                                                                                         |
| `allowFreeInput`     | `freeform` + controlled pending state | Match an option or restore the previous selection on blur; do not commit unmatched text |
| `autoComplete`       | Custom controlled behavior            | v9's native attribute does not reproduce v8 inline option completion                    |
| `label`              | `<Field label="...">` wrapper         |                                                                                         |
| `placeholder`        | `placeholder`                         |                                                                                         |
| `disabled`           | `disabled`                            |                                                                                         |
| `multiSelect`        | `multiselect`                         |                                                                                         |
| `text` (display val) | `value`                               | The text shown in the input                                                             |
| `errorMessage`       | `validationMessage` on `<Field>`      |                                                                                         |
| `styles`             | `className` + `makeStyles`            |                                                                                         |
| `theme`              | `FluentProvider`                      |                                                                                         |
| `componentRef`       | `ref`                                 |                                                                                         |
