# Stack.Item Migration

## Overview

Fluent UI v9 does not provide a native `Stack.Item` component. Replace it with
an element styled using CSS flex item properties. During an incremental
migration, `StackItemShim` from `@fluentui/react-migration-v8-v9` accepts the
v8 `Stack.Item` props.

## Prop Mapping

The sections below map each v8 `Stack.Item` prop to CSS flex-item properties or
the corresponding v9 migration approach; there is no native v9 `Stack.Item`
prop API.
