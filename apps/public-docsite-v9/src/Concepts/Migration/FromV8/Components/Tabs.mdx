# Tabs (Pivot) Migration

## Overview

Fluent UI v8's `Pivot` and `PivotItem` migrate to v9's `TabList` and `Tab` composition, with tab labels and content represented separately.

## v8 Pivot & PivotItem

In v8, you declare a `Pivot` with a list of `PivotItem` components as children.

- The tab name is declared in the `headerText` property.
- The associated content for each tab is declared within the `PivotItem`.
- This binds the tab and tab content together in the DOM hierarchy.

For example,

```tsx
<Pivot>
  <PivotItem headerText="First Tab">
    <Label>Content 1</Label>
  </PivotItem>
  <PivotItem headerText="Second Tab">
    <Label>Content 2</Label>
  </PivotItem>
  <PivotItem headerText="Third Tab">
    <Label>Content 3</Label>
  </PivotItem>
</Pivot>
```

## v9 TabList & Tab

In v9, there is a similar approach of a `TabList` containing `Tab` components.

The key difference is the `Tab` children are rendered as the label of the tab.

- The associated content that is shown/hidden is separate from the `Tab` and `TabList`.
- This allows for much richer tab label, for the associated content to be placed anywhere in the DOM,
  and for more control over when and how associated content is rendered.

### Migration Steps

To migrate from `Pivot` to `TabList`

- replace `Pivot` with `TabList` and `PivotItem` with `Tab`
- move all the `PivotItem` content under a sibling element of `TabList`
- move the `headerText` into the `Tab`'s children.
- add the `onTabSelect` event handler to set the selected tab value as state
- update the content element to render the selected tabs content.

Moving panels outside `TabList` also makes their surrounding layout explicit.
Preserve the source's fill and width behavior, and style the tab strip, panel
region, fields, and adjacent status or help content as one composition. Use
Fluent spacing tokens for gaps and padding; do not add arbitrary maximum
widths merely to compact the example.

For example, here is the previous `Pivot` example migrated to use `TabList`

```tsx
const [selectedValue, setSelectedValue] = React.useState<TabValue>('tab1');

const onTabSelect = (event: SelectTabEvent, data: SelectTabData) => {
  setSelectedValue(data.value);
};

//...

<>
  <TabList selectedValue={selectedValue} onTabSelect={onTabSelect}>
    <Tab id="tab1" value="tab1" aria-controls="panel1">
      First Tab
    </Tab>
    <Tab id="tab2" value="tab2" aria-controls="panel2">
      Second Tab
    </Tab>
    <Tab id="tab3" value="tab3" aria-controls="panel3">
      Third Tab
    </Tab>
  </TabList>
  <div>
    <div id="panel1" role="tabpanel" aria-labelledby="tab1" hidden={selectedValue !== 'tab1'}>
      Content 1
    </div>
    <div id="panel2" role="tabpanel" aria-labelledby="tab2" hidden={selectedValue !== 'tab2'}>
      Content 2
    </div>
    <div id="panel3" role="tabpanel" aria-labelledby="tab3" hidden={selectedValue !== 'tab3'}>
      Content 3
    </div>
  </div>
</>;
```

v8 selects the first `PivotItem` when neither `selectedKey` nor
`defaultSelectedKey` is supplied. v9 `TabList` has no implicit initial
selection, so initialize controlled state to the first value as above, or use
`defaultSelectedValue="tab1"` for an uncontrolled list.

The canonical v9 panel pattern gives each `Tab` a stable `id` and each panel
`role="tabpanel"` plus `aria-labelledby`. When panels stay mounted, also connect
each tab with `aria-controls`.

v8 `PivotItem alwaysRender` keeps inactive content mounted. Preserve that
behavior by rendering every stateful panel and toggling the HTML `hidden`
attribute. Conditional rendering unmounts inactive panels and loses local
state, focus, and pending work.

## Prop Mapping

| v8                 | v9                             |
| ------------------ | ------------------------------ |
|                    | appearance                     |
| componentRef       | ref                            |
| className          | className                      |
| defaultSelectedKey | defaultSelectedValue           |
| focusZoneProps     | (removed)                      |
| getTabId           | (removed)                      |
| headersOnly        | (removed)                      |
| linkFormat         | (removed)                      |
| linkSize           | size                           |
| onLinkClick        | onTabSelect                    |
| overflowAriaLabel  | (removed)                      |
| overflowBehavior   | (removed)                      |
| selectedKey        | selectedValue                  |
| styles             | (use makeStyles and className) |
| theme              | (use FluentProvider)           |
|                    | vertical                       |

| headerButtonProps | (removed)                               |
| itemKey           | value                                   |
| ariaLabel         | aria-label                              |
| itemCount         | (removed)                               |
| itemIcon          | icon (slot)                             |
| onRenderItemLink  | (removed)                               |
| keytipProps       | (removed)                               |
