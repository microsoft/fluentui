# Textarea Migration

## Overview

Fluent UI v8 provides the `TextField` control to allow users to enter and edit text. Fluent UI v9 provides a `Textarea` control, but has a different API.

v9 takes a different approach to text inputs. Instead of a single `TextField` component, it uses separate `Input` and `Textarea` components. v9's `Input` replaces a single-line v8 `TextField`, while v9's `Textarea` replaces a v8 `TextField` with `multiline`.

## Examples

### Basic Migration

Basic usage of `TextField` v8

```tsx
import React from 'react';
import { TextField } from '@fluentui/react/lib/TextField';

const TextareaV8BasicExample = () => {
  return (
    <>
      <TextField label="Standard" multiline rows={3} />
      <TextField label="Disabled" multiline rows={3} disabled defaultValue="Example text" />
      <TextField label="Non-resizable" multiline resizable={false} />
    </>
  );
};

export default TextareaV8BasicExample;
```

An equivalent `Textarea` in v9 is

```tsx
import * as React from 'react';
import { Label, Textarea } from '@fluentui/react-components';
import { useId } from '@fluentui/react-utilities';

const TextareaV9BasicExample = () => {
  const standardTextareaId = useId('standard');
  const disabledTextareaId = useId('disabled');
  const nonResizableTextareaId = useId('nonResizable');

  return (
    <>
      <div>
        <Label htmlFor={standardTextareaId}>Standard</Label>
        <Textarea id={standardTextareaId} rows={3} />
      </div>
      <div>
        <Label disabled htmlFor={disabledTextareaId}>
          Disabled
        </Label>
        <Textarea defaultValue="Example text" disabled id={disabledTextareaId} rows={3} />
      </div>
      <div>
        <Label htmlFor={nonResizableTextareaId}>Non-resizable</Label>
        <Textarea resize="none" id={nonResizableTextareaId} />
      </div>
    </>
  );
};
```

### Validation

Wrap `Textarea` in `Field` for validation. `Field validationState` and
`validationMessage` provide the visual state, `aria-invalid`, message
association, and error/warning announcement behavior:

```tsx
import * as React from 'react';
import { Field, Textarea } from '@fluentui/react-components';
import type { TextareaProps } from '@fluentui/react-components';

const ValidatedTextarea = ({ validate }: { validate: (value: string) => Promise<string> }) => {
  const [value, setValue] = React.useState('');
  const [message, setMessage] = React.useState('');
  const requestSequence = React.useRef(0);

  const onChange: TextareaProps['onChange'] = (_, data) => {
    requestSequence.current += 1;
    setValue(data.value);
  };
  const validateCurrentValue = async () => {
    const sequence = ++requestSequence.current;
    const nextMessage = await validate(value);
    if (sequence === requestSequence.current) {
      setMessage(nextMessage);
    }
  };

  return (
    <Field label="Description" validationState={message ? 'error' : 'none'} validationMessage={message || undefined}>
      <Textarea value={value} onChange={onChange} onBlur={validateCurrentValue} />
    </Field>
  );
};
```

This example matches `validateOnFocusOut`. For `validateOnFocusIn`, call the
sequenced validator from `onFocus`; when both v8 flags were true, validate on
both. For the default v8 change-driven policy, debounce validation from
`onChange` by `deferredValidationTime`. Preserve `validateOnLoad` by running
validation on mount only when the old control did. Cancel or sequence async
requests so stale results cannot replace or announce the current result.

## Prop Mapping

This table maps `TextField` v8 props to the `Textarea` v9 equivalent.

| v8                         | v9                              | Notes                                                                     |
| -------------------------- | ------------------------------- | ------------------------------------------------------------------------- |
| `ariaLabel`                | aria-label                      |                                                                           |
| `autoAdjustHeight`         | n/a                             | Implement content-based autosizing separately                             |
| `className`                | `className`                     | Applies to the root wrapper                                               |
| `autoComplete`             | `autoComplete`                  |                                                                           |
| `borderless`               | `appearance`                    | Equivalent `appearance` could be either `filledLighter` or `filledDarker` |
| `canRevealPassword`        | n/a                             |                                                                           |
| `componentRef`             | `ref`                           | v9 provides access to the underlying `<textarea>` element                 |
| `defaultValue`             | `defaultValue`                  | Mutually exclusive with `value`                                           |
| `deferredValidationTime`   | App-owned debounce              | Preserve the v8 validation delay                                          |
| `description`              | n/a                             |                                                                           |
| `disabled`                 | `disabled`                      |                                                                           |
| `errorMessage`             | `Field validationMessage`       | `Field` associates and announces the message                              |
| `iconProps`                | n/a                             |                                                                           |
| `inputClassName`           | `textarea`                      | Pass a class name through the `textarea` slot                             |
| `invalid`                  | `Field validationState="error"` | `Field` supplies invalid semantics                                        |
| `label`                    | n/a                             | To add a label, use the `Label` component                                 |
| `multiline`                | n/a                             | `Textarea` is multiline by default                                        |
| `onChange`                 | `onChange`                      |                                                                           |
| `onGetErrorMessage`        | App-owned validator + `Field`   | Preserve async behavior and stale-result protection                       |
| `onNotifyValidationResult` | App-owned validation state      | Notify only when the current result is applied                            |
| `onRenderDescription`      | n/a                             |                                                                           |
| `onRenderInput`            | n/a                             |                                                                           |
| `onRenderLabel`            | n/a                             |                                                                           |
| `onRenderPrefix`           | n/a                             |                                                                           |
| `onRenderSuffix`           | n/a                             |                                                                           |
| `prefix`                   | n/a                             |                                                                           |
| `readOnly`                 | `readOnly`                      | This is a native HTML prop applied to the `<textarea>`                    |
| `resizable`                | `resize`                        |                                                                           |
| `revealPasswordAriaLabel`  | n/a                             |                                                                           |
| `styles`                   | `className`                     |                                                                           |
| `suffix`                   | n/a                             |                                                                           |
| `theme`                    | n/a                             | Use `FluentProvider` to customize themes                                  |
| `underlined`               | n/a                             |                                                                           |
| `validateOnFocusIn`        | Validate from `onFocus`         | Preserve v8 timing policy                                                 |
| `validateOnFocusOut`       | Validate from `onBlur`          | Preserve v8 timing policy                                                 |
| `validateOnLoad`           | Initial app-owned validation    | Run or skip validation on mount to match v8                               |
| `value`                    | `value`                         | Mutually exclusive with `defaultValue`                                    |
