# Textarea Migration

Fluent UI v8 provides the `TextField` control to allow users to enter and edit text. Fluent UI v9 provides a `Textarea` control, but has a different API.

v9 takes a different approach to text inputs. Instead of a single `TextField` component, it uses separate `Input` and `Textarea` components. v9's `Input` replaces a single-line v8 `TextField`, while v9's `Textarea` replaces a v8 `TextField` with `multiline`.

## Examples

### Basic Migration

Basic usage of `TextField` v8

```tsx
import React from 'react';
import { TextField } from '@fluentui/react/lib/TextField';

const TextareaV8BasicExample = () => {
  return (
    <>
      <TextField label="Standard" multiline rows={3} />
      <TextField label="Disabled" multiline rows={3} disabled defaultValue="Example text" />
      <TextField label="Non-resizable" multiline resizable={false} />
    </>
  );
};

export default TextareaV8BasicExample;
```

An equivalent `Textarea` in v9 is

```tsx
import * as React from 'react';
import { Label, Textarea } from '@fluentui/react-components';
import { useId } from '@fluentui/react-utilities';

const TextareaV9BasicExample = () => {
  const standardTextareaId = useId('standard');
  const disabledTextareaId = useId('disabled');
  const nonResizableTextareaId = useId('nonResizable');

  return (
    <>
      <div>
        <Label htmlFor={standardTextareaId}>Standard</Label>
        <Textarea id={standardTextareaId} rows={3} />
      </div>
      <div>
        <Label disabled htmlFor={disabledTextareaId}>
          Disabled
        </Label>
        <Textarea defaultValue="Example text" disabled id={disabledTextareaId} rows={3} />
      </div>
      <div>
        <Label htmlFor={nonResizableTextareaId}>Non-resizable</Label>
        <Textarea resize="none" id={nonResizableTextareaId} />
      </div>
    </>
  );
};
```

## Prop Mapping

This table maps `TextField` v8 props to the `Textarea` v9 equivalent.

| v8                         | v9             | Notes                                                                     |
| -------------------------- | -------------- | ------------------------------------------------------------------------- |
| `ariaLabel`                | aria-label     |                                                                           |
| `autoAdjustHeight`         | n/a            | Implement content-based autosizing separately                             |
| `className`                | `className`    | Applies to the root wrapper                                               |
| `autoComplete`             | `autoComplete` |                                                                           |
| `borderless`               | `appearance`   | Equivalent `appearance` could be either `filledLighter` or `filledDarker` |
| `canRevealPassword`        | n/a            |                                                                           |
| `componentRef`             | `ref`          | v9 provides access to the underlying `<textarea>` element                 |
| `defaultValue`             | `defaultValue` | Mutually exclusive with `value`                                           |
| `deferredValidationTime`   | n/a            |                                                                           |
| `description`              | n/a            |                                                                           |
| `disabled`                 | `disabled`     |                                                                           |
| `errorMessage`             | n/a            |                                                                           |
| `iconProps`                | n/a            |                                                                           |
| `inputClassName`           | `textarea`     | Pass a class name through the `textarea` slot                             |
| `invalid`                  | n/a            |                                                                           |
| `label`                    | n/a            | To add a label, use the `Label` component                                 |
| `multiline`                | n/a            | `Textarea` is multiline by default                                        |
| `onChange`                 | `onChange`     |                                                                           |
| `onGetErrorMessage`        | n/a            |                                                                           |
| `onNotifyValidationResult` | n/a            |                                                                           |
| `onRenderDescription`      | n/a            |                                                                           |
| `onRenderInput`            | n/a            |                                                                           |
| `onRenderLabel`            | n/a            |                                                                           |
| `onRenderPrefix`           | n/a            |                                                                           |
| `onRenderSuffix`           | n/a            |                                                                           |
| `prefix`                   | n/a            |                                                                           |
| `readOnly`                 | `readOnly`     | This is a native HTML prop applied to the `<textarea>`                    |
| `resizable`                | `resize`       |                                                                           |
| `revealPasswordAriaLabel`  | n/a            |                                                                           |
| `styles`                   | `className`    |                                                                           |
| `suffix`                   | n/a            |                                                                           |
| `theme`                    | n/a            | Use `FluentProvider` to customize themes                                  |
| `underlined`               | n/a            |                                                                           |
| `validateOnFocusIn`        | n/a            |                                                                           |
| `validateOnFocusOut`       | n/a            |                                                                           |
| `validateOnLoad`           | n/a            |                                                                           |
| `value`                    | `value`        | Mutually exclusive with `defaultValue`                                    |
