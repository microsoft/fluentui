## Focus indicator

Fluent UI components use [tabster](https://github.com/microsoft/tabster) for focus handling functionality, so that they can be easily integrated with application-level tabster functionality such as delooser and cross-iframe focusing.

Fluent UI `@fluentui/react-tabster` package defines `useKeyboardNavAttribute` (and the `data-fui-focus-visible` / `data-fui-focus-within` attributes) to integrate tabster keyboard navigation mechanism seemlesly within Fluent UI.

### useKeyboardNavAttribute

Instantiates [keyborg](https://github.com/microsoft/keyborg) and adds `data-keyboard-nav` attribute to a referenced element to ensure keyboard navigation awareness synced to keyborg logic without having to cause a re-render on react tree.

```tsx
function Root() {
  const ref = useKeyboardNavAttribute();
  return <div ref={ref}>{children}</div>;
}
```

```html
<!-- data-keyboard-nav is present when navigating with keyboard -->
<div data-keyboard-nav="">
  <!-- ... -->
</div>
<!-- data-keyboard-nav is not present when navigating with mouse -->
<div>
  <!-- ... -->
</div>
```

### Styling focus indicators

The default focus indicator used in Fluent UI is an outline. However, in some cases more specific focus indicators are necessary depending on the use case and component design. Two approaches cover these requirements:

1. the shared `fui-focus-outline` CSS utility (the default ring)
2. custom focus indicator declarations under a focus variant

Both are powered using the method described above.

#### The default outline (`fui-focus-outline`)

The [AccordionHeader](?path=/docs/components-accordion--default) component uses the shared focus-outline utility to style the default outline style when focus is detected

  <FluentStory id="components-accordion--default" height={260} />
</FluentCanvas>

The indicator is a shared CSS utility, `fui-focus-outline`, from `@fluentui/react-tailwind-theme`.
It draws the ring on an `::after` pseudo-element, so the element it is applied to must be
positioned. Apply it under whichever focus variant you want:

| Variant             | Matches                                                                       |
| ------------------- | ----------------------------------------------------------------------------- |
| `focus-visible-fui` | `[data-fui-focus-visible]` — keyborg's keyboard-only signal, the usual choice |
| `focus-within-fui`  | `[data-fui-focus-within]:focus-within` — pairs with `useFocusWithin()`        |
| `focus-visible`     | the plain CSS `:focus-visible`                                                |
| `focus-within`      | the plain CSS `:focus-within`                                                 |

```css
/* Component.module.css */
@reference '#theme';

@layer fui.theme, fui.base, fui.components, fui.components.l1, fui.components.l2, fui.components.l3, fui.components.l4, fui.components.l5, fui.utilities;

@layer fui.components.l4 {
  .focus-indicator {
    position: relative;

    &:focus,
    &:focus-visible {
      outline-style: none;
    }

    @variant focus-within-fui {
      @apply fui-focus-outline;
    }
  }
}
```

```tsx
import styles from './Component.module.css';

function Component() {
  return <div className={styles['focus-indicator']} />;
}
```

The ring is parameterized by four custom properties, each with the default shown. Set them on the
same rule to customize width, colour, radius or offset:

```css
.focus-indicator {
  --fui-focus-outline-width: 2px;
  --fui-focus-outline-color: var(--color-stroke-focus-2);
  --fui-focus-outline-radius: var(--radius-medium);
  --fui-focus-outline-offset: 0px;
}
```

> The Griffel-era `createFocusOutlineStyle` helper has been removed from
> `@fluentui/react-tabster` — the `fui-focus-outline` utility above is its replacement.

#### Custom focus indicators

> ⚠️ A bad focus indicator can have serious accessibility consequences and can render
> your experience unusable by certain user. Please ensure before creating a custom focus
> indicator that you have gotten the necessary feedback from designers and accessibility
> experts.

The [Link](?path=/docs/components-link--default) component replaces the default ring with a double
underline instead.

<FluentCanvas>
  <FluentStory id="components-link--default" height={150} />
</FluentCanvas>

There is no helper for this — write the declarations you want under the same focus variant, and do
not apply `fui-focus-outline`:

```css
/* MyLink.module.css */
@reference '#theme';

@layer fui.theme, fui.base, fui.components, fui.components.l1, fui.components.l2, fui.components.l3, fui.components.l4, fui.components.l5, fui.utilities;

@layer fui.components.l4 {
  .focus-indicator {
    &:focus,
    &:focus-visible {
      outline-style: none;
    }

    @variant focus-visible-fui {
      border-bottom-color: transparent;
      text-decoration-color: var(--color-stroke-focus-2);
      text-decoration-line: underline;
      text-decoration-style: double;
    }
  }
}
```

```tsx
import styles from './MyLink.module.css';

function Link() {
  return <a className={styles['focus-indicator']} />;
}
```

> The Griffel-era `createCustomFocusIndicatorStyle` helper has been removed from
> `@fluentui/react-tabster` along with `createFocusOutlineStyle` — write the focus-variant
> declarations directly, as above.
