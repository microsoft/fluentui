---
title: Supported Platforms
---

Learn about the platforms that are supported by Fluent UI React.

## Browser

Fluent UI supports the latest, stable releases of all major browsers and platforms.

Please refer to the [Browser Support Matrix](/react/concepts/developer/browser-support-matrix) for more details.

## React

Fluent UI fully supports React versions 17, 18 and 19.

Please refer to the [React Version Support](/react/concepts/developer/react-version-support) for more details.

## TypeScript

Fluent UI supports the three latest **major** versions of TypeScript.

> Older TypeScript versions might still work, but they are outside the supported range.

Please refer to the [Fluent UI TypeScript Contract](https://github.com/microsoft/fluentui/blob/master/docs/react-v9/contributing/rfcs/shared/types-contract.md) for more details.
