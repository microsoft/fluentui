### Components with motion slots

The Fluent v9 components below expose one or more motion slots. The **Example** column links to a motion-specific story in that component's own package.

| Component                                                     | Slots                             | Example                                                                                                              |

| [DialogSurface](/react/components/dialog#backdrop-appearance) | `backdropMotion`                  | [BackdropAppearance](/react/components/dialog#backdrop-appearance)                                                   |
| [InlineDrawer](/react/components/drawer#inline)               | `surfaceMotion`                   | [MotionCustom](/react/components/drawer#motion-custom)                                                               |
| [OverlayDrawer](/react/components/drawer#overlay)             | `backdropMotion`, `surfaceMotion` | [MotionCustom](/react/components/drawer#motion-custom), [MotionDisabled](/react/components/drawer#motion-disabled)   |
| [Menu](/react/components/menu)                                | `surfaceMotion`                   | [MotionCustom](/react/components/menu#motion-custom), [MotionDisabled](/react/components/menu#motion-disabled)       |
| [NavCategoryItem](/react/components/nav)                      | `expandIconMotion`                | [CustomMotion](/react/components/nav#custom-motion)                                                                  |
