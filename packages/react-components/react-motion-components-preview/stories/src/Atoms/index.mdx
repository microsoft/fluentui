## What are Motion Atoms?

In the Fluent Motion System's <a href="?path=/docs/motion-introduction--docs#an-atomic-motion-system">atomic model</a>, **atoms** are single one-way animations — keyframes changing one property over time. They're the foundation that <a href="?path=/docs/motion-components-preview-introduction--docs">Motion Components</a> (molecules) are built from.

Each atom is a factory function that returns an `AtomMotion` object — a plain description of keyframes, duration, and easing that the browser can execute directly.

```ts
import { blur } from '@fluentui/react-motion-components-preview';

const blurMotion = blur({
  duration: 500,
  from: '10px',
  to: '0px',
});
// Returns: { keyframes: [{ filter: 'blur(10px)' }, { filter: 'blur(0px)' }], duration: 500, easing: '...', delay: 0 }
```

## Available Atoms

| Atom     | Effect               | CSS Property     | Neutral Value | Key Parameters       |
| -------- | -------------------- | ---------------- | ------------- | -------------------- |
| `fade`   | Opacity transition   | `opacity`        | `1`           | `from`, `to`         |
| `scale`  | Size scaling         | `scale`          | `1`           | `from`, `to`         |
| `slide`  | Position translation | `translate`      | `'0px' '0px'` | `from`, `to`         |
| `rotate` | 3D rotation          | `rotate`         | `0` degrees   | `axis`, `from`, `to` |
| `blur`   | Blur filter          | `filter: blur()` | `'0px'`       | `from`, `to`         |

The legacy `*Atom` helpers (`fadeAtom`, `scaleAtom`, `slideAtom`, `rotateAtom`, `blurAtom`) are deprecated compatibility APIs that retain their original `direction` and out/in parameters. New code should use the temporal `from`/`to` helpers or their `*In`/`*Out` counterparts.

## Atom API Reference

### Common Parameters

All atoms accept these base parameters:

| Parameter  | Type     | Default       | Description                            |
| ---------- | -------- | ------------- | -------------------------------------- |
| `duration` | `number` | —             | **Required.** Animation duration in ms |
| `easing`   | `string` | `curveLinear` | CSS easing function                    |
| `delay`    | `number` | `0`           | Delay before animation starts          |

General atoms (`fade`, `scale`, `slide`, `rotate`, `blur`) animate `from` to `to`, with at least one endpoint required. An omitted endpoint defaults to the property's neutral value: opacity `1`, scale `1`, zero translation (`0px`), `0` degrees (axis `'z'`), or blur `'0px'`. Fade helpers set `fill: 'both'` so delayed fades stay hidden; the other atoms do not add a fade or set `fill`. Neutral atom defaults differ from the presence components' Fluent entrance defaults.

Directional `*In` and `*Out` helpers encode the neutral-value boundary: `*In` arrives at neutral (`to` is forbidden), and `*Out` departs from neutral (`from` is forbidden). `fadeIn`/`fadeOut` and `scaleIn`/`scaleOut` accept an optional outer endpoint that defaults to `0`. `slideIn`/`slideOut`, `rotateIn`/`rotateOut`, and `blurIn`/`blurOut` require their outer endpoint because they have no universal displaced value. Use the general helper when authoring two non-neutral endpoints.

Legacy `*Atom` helpers additionally require `direction: 'enter' | 'exit'`, which selects out-to-in or in-to-out keyframe order.

### Per-Atom Parameters

In addition to the common parameters above, each atom has specific properties:

```ts
import {
  fade,
  fadeIn,
  fadeOut,
  scale,
  scaleIn,
  scaleOut,
  slide,
  slideIn,
  slideOut,
  rotate,
  rotateIn,
  rotateOut,
  blur,
  blurIn,
  blurOut,
} from '@fluentui/react-motion-components-preview';

// Opacity (0 to 1; optional outer endpoint defaults to 0 on fadeIn/fadeOut)
fade({ duration: 500, from: 0.2, to: 0.8 });
fadeIn({ duration: 500 });
fadeOut({ duration: 500, to: 0.2 });

// Scale (unitless factor; optional outer endpoint defaults to 0 on scaleIn/scaleOut)
scale({ duration: 500, from: 0.8, to: 1.2 });
scaleIn({ duration: 500, from: 0.9 });
scaleOut({ duration: 500 });

// Translation with CSS lengths (omitted axis defaults to '0px')
slide({ duration: 500, from: { y: '20px' }, to: { y: '0px' } });
slideIn({ duration: 500, from: { y: '20px' } });
slideOut({ duration: 500, to: { x: '24px' } });

// Rotation in degrees (axis: 'x' | 'y' | 'z')
rotate({ duration: 600, axis: 'y', from: -90, to: 45 });
rotateIn({ duration: 600, from: -90 });
rotateOut({ duration: 600, to: 90 });

// Blur with CSS lengths
blur({ duration: 500, from: '1rem', to: '2px' });
blurIn({ duration: 500, from: '10px' });
blurOut({ duration: 500, to: '10px' });
```

## Creating Custom Presence Components

The real power of atoms is **composing** them. Pass an array of atoms to `createPresenceComponent` and they run in parallel — creating richer effects from simple building blocks:

<ComposingAtomsDemo />

Multiple atoms in an array animate simultaneously. Use the same duration for a cohesive feel, or intentionally vary them for more complex choreography.

### Dynamic Parameters

Use the function form to access runtime values like element dimensions:

```tsx
const DynamicSlide = createPresenceComponent(({ element }) => {
  const width = element.offsetWidth;
  return {
    enter: slideIn({ duration: 500, from: { x: `-${width}px` } }),
    exit: slideOut({ duration: 500, to: { x: `-${width}px` } }),
  };
});
```

## When to Use Atoms

| Use Case                                       | Recommendation                                                  |
| ---------------------------------------------- | --------------------------------------------------------------- |
| Standard fade, scale, slide                    | Use pre-built components (`Fade`, `Scale`, etc.)                |
| Custom combination of effects                  | Compose atoms into a new presence component                     |
| Unique animation not covered by existing atoms | Create custom keyframes directly with `createPresenceComponent` |
| Dynamic animations based on element size       | Use atoms with the function form                                |
