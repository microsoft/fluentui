The headless `TeachingPopover` is built on top of the headless `Popover`. It adds a structured header / title / body / footer composition and an optional paged carousel — without styling. Bring your own CSS.

`TeachingPopover` re-uses the `@fluentui/react-teaching-popover` base hooks for its sub-components (`Header`, `Title`, `Footer`, `Carousel*`) and bridges the `@fluentui/react-popover` `PopoverContext` internally so dismiss buttons, finish handlers, and the carousel state machine all work transparently.

### Carousel boundary focus recovery

When an accepted carousel update replaces a focused navigation button's content with `altText={null}` and your presentation hides or disables that now-empty action, headless recovers focus in this order: the eligible paired navigation button, the first eligible control in the accepted active card, then the active card container. Navigation targets must be connected, visible, enabled, outside inert or accessibility-hidden content, and keyboard-focusable. Null alternate text alone does not hide an action or move focus; visible alternative content keeps focus. Rejected controlled updates do not move focus, and delayed acceptance only recovers while the original control still owns focus.

Moving focus elsewhere, including out of the owning iframe, or explicitly blurring the source while it is still available cancels recovery. A browser may instead drop focus to the document body when a committed update hides the source; that fallback may recover while the document still has focus. Explicit blur after the source is already hidden is indistinguishable from that native fallback. Outside-focus tracking remains active during commits, including when the outside target is subsequently blurred.

The footer hook owns recovery privately; the carousel renderer supplies its owning root and committed value through a private context. Focus ownership belongs to the concrete source element: same-element ref reattachment and alternate-text updates preserve it while that element remains focused, while a replacement must acquire focus itself. If no eligible destination exists yet, observation retries after relevant committed DOM changes. Completed recovery is not repeated when another destination later becomes available.

Card-container fallback preserves a consumer-provided `tabindex`, including one adopted while the card is focused. Otherwise headless temporarily adds `tabindex="-1"` until the card blurs or disconnects, independently of the footer's lifetime and without adding the card to the sequential Tab order. Native editing hosts participate in control recovery unless explicitly excluded with a negative tabindex. Availability observation includes existing reachable open shadow roots and roots discovered after an observed DOM change; attaching a new shadow root to an existing host without an observable light-DOM change does not itself notify a MutationObserver. Headless does not add headings, roles, accessible names, or live announcements. CSS `content-visibility: hidden` on a button itself skips its contents, not its focusable box; skipped ancestor contents remain unavailable. A button's own `display: contents` removes its box, unlike that property on an ancestor.

Presentation adapters use `renderTeachingPopoverCarousel` and preserve the effective carousel root ref, footer slots/root refs, and focus/blur handlers, plus the button hook's normalized root fields when adding styling. Rebuilding slots from raw consumer props bypasses behavior. When replacing a slot component, update both its `elementType` and corresponding `state.components` entry. No extra public provider, renderer arguments, props, or API changes are required. Consumer-hidden non-empty navigation is a separate contract from this semantic boundary recovery.

Carousel footer buttons default to `type="button"` rather than submitting surrounding forms; an explicit `type="submit"` is preserved. Anchor roots use button keyboard and disabled semantics. The paired handoff does not focus headings, announce pages, or change dismissal behavior.
