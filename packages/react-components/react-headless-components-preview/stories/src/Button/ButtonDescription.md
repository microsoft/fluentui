A button triggers a single action or event.

Use buttons for important actions like submitting a response, committing a change, or moving to the next step. For navigating to another place, try a link instead.

This headless Button exposes state data attributes for custom styling, listed in the API Reference below.
`data-icon-position` is only set when an icon is present. These attributes belong to the headless Button,
not the styled v9 Button.
