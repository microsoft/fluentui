A slider lets users select a value from a continuous range by dragging a thumb along a track.

Use Slider for settings where the approximate value matters more than precision, such as volume, brightness, or zoom level. When an exact number is required use SpinButton or Input instead.

The input's `aria-orientation` defaults to `vertical` when `vertical` is true and `horizontal` otherwise. An explicit `aria-orientation` on the component or its `input` slot takes precedence over this default.
