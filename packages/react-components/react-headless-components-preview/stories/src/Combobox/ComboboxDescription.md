A combobox (`Combobox`) combines a text field and a dropdown giving people a way to select an option from a list or enter their own choice.

The expand icon is a separate accessible button that supports pointer and click-only activation. Enter or Space toggles the listbox; Escape closes an open listbox and returns focus to the input without dismissing a parent dialog. Provide a localized accessible name through the `expandIcon` slot's `aria-label` or `aria-labelledby`.
