Typography style is represented by a set of tokens instead of an individual token. The tokens are used to create and share a consistent look and feel.

> **ℹ️ &nbsp;This page guides you on how to fully leverage the tokens to create a consistent typography system.<br />
> To take full advantage of the typography system, you should also read the [Text component documentation](./?path=/docs/components-text--docs).**

## How to use

A typography ramp is four token custom properties — family, size, weight and line height — so in CSS
you apply one by writing those four declarations. This is exactly what `Title2` and the other presets
do internally:

```css
/* Example.module.css */
.text {
  font-family: var(--font-base);
  font-size: var(--text-hero-700);
  font-weight: var(--font-weight-semibold);
  line-height: var(--leading-hero-700);
}
```

```tsx
import styles from './Example.module.css';

export const Example = () => <span className={styles.text}>Text using tokens</span>;
```

The `typographyStyles` object remains exported for code that needs the same values from
TypeScript (for example, to feed an inline `style` or a charting library) — but for styling,
the CSS Module above is the whole recipe.

## Composing Tokens

Besides using a full typography ramp, you can still compose individual typography tokens:

```css
/* Composing.module.css */
.text {
  font-family: var(--font-monospace);
  font-size: var(--text-base-600);
  font-weight: var(--font-weight-bold);
  line-height: var(--leading-base-600);
}
```

```tsx
import * as React from 'react';

import styles from './Composing.module.css';

export const Composing = () => <span className={styles.text}>Custom text using only tokens</span>;
```

## Mixing tokens and custom styles

To mix tokens and custom styles, start a class from a ramp's four declarations and add any other
CSS properties next to them:

```css
/* MixedStyles.module.css */
.title {
  /* Title 2 ramp */
  font-family: var(--font-base);
  font-size: var(--text-hero-700);
  font-weight: var(--font-weight-semibold);
  line-height: var(--leading-hero-700);
}

.paragraph {
  /* Body 1 ramp */
  font-family: var(--font-base);
  font-size: var(--text-base-300);
  font-weight: var(--font-weight-regular);
  line-height: var(--leading-base-300);
  /* custom additions */
  letter-spacing: 0.0675em;
  font-style: italic;
}
```

```tsx
import * as React from 'react';
import { Text } from '@fluentui/react-components';

import styles from './MixedStyles.module.css';

export const MixedStyles = () => (
  <div>
    <Text as="h1" block className={styles.title}>
      Using Title 2 tokens
    </Text>

    <Text as="p" block className={styles.paragraph}>
      I'm a paragraph using Body 1 tokens and customized styles
    </Text>
  </div>
);
```
