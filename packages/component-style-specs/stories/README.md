# Component Style Specs Stories

Side-by-side Storybook demos for the Component Style Spec PoC:

- **Shipped v9** — `@fluentui/react-components` Badge / Button / Divider
- **Generated Griffel** — hooks emitted by `@fluentui/style-spec-compilers` (fixtures)
- **CSS Module / styled headless** — generated `.module.css` + `get*ClassNames` helpers

```sh
yarn nx run component-style-specs-stories:storybook
```
